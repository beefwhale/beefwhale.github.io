
# Yongqing's Webspace
built with Jekyll and Chirpy and deployed with Github Pages.

Visit the site: https://beefwhale.github.io/
  
# Setup and Testing on localhost

1. Download Ruby, Jekyll, and Node.js.
2. Run `npm install` to install the local spelling checker.
3. Build with `bundle exec jekyll build`.
4. Run with `bundle exec jekyll s` or `bundle exec jekyll s --unpublish`

# Create a Post

Use the `new-post` script to create an empty, hidden post. Pass the post title as
an argument:

```sh
./new-post "My Post Name"
```

Run `./new-post --help` to see all available flag options.
